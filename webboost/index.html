Política de privacidad

Versión vigente: 2.1.2 · Última actualización: 12 de agosto de 2026

WebBoost funciona localmente y no transmite datos a ShiroLabs ni a terceros.

Procesamiento local

Para aplicar sus funciones, la extensión procesa temporalmente elementos de la página actual, orígenes de enlaces, visibilidad de imágenes e iframes, estadísticas técnicas de reproducción y gestos de intención sobre enlaces. Este procesamiento ocurre dentro del navegador.

No se guardan URLs, contenido de páginas, búsquedas, formularios, comunicaciones, nombres de archivos descargados ni historial de movimientos del puntero.

Datos guardados

  • Tema y preferencias de rendimiento, vídeo, bloqueo y caché.
  • Perfil de conexión y perfil DNS seleccionados.
  • Contadores agregados de páginas, tiempo protegido, imágenes diferidas y páginas anticipadas.
  • Estimación acumulada de transferencia evitada.
  • Fecha y número de limpiezas de caché.

Transmisión y terceros

WebBoost no transmite telemetría ni datos personales, no vende ni comparte información y no permite acceso humano a los datos procesados. No utiliza los datos para publicidad, elaboración de perfiles, evaluación crediticia ni seguimiento entre sitios.

DNS

La selección de un perfil DNS se guarda localmente. WebBoost no envía consultas DNS, no actúa como proxy y no modifica automáticamente el DNS. El usuario debe confirmar cualquier cambio en la configuración del navegador.

Control y eliminación

Las preferencias y métricas pueden reiniciarse desde la extensión. Al desinstalar WebBoost, el navegador elimina su almacenamiento local. La limpieza de caché es una acción independiente y explícita.

Permisos

  • storage: preferencias y métricas locales.
  • activeTab y tabs: estado técnico de la pestaña activa y comunicación con páginas optimizadas.
  • alarms: limpieza automática opcional.
  • browsingData: limpieza de caché solicitada por el usuario.
  • declarativeNetRequest: reglas locales contra anuncios, rastreadores y minería.
  • clipboardWrite: copia del endpoint DNS elegido mediante una acción explícita.

Uso limitado

El uso de información recibida mediante las API de Google cumple la Política de Datos de Usuario de Chrome Web Store, incluidos sus requisitos de Uso Limitado. Toda información procesada se utiliza exclusivamente para proporcionar las funciones visibles de rendimiento y privacidad de WebBoost.
